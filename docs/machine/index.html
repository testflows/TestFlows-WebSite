Deterministic simulation testing for developers and AI coding agents

Test and explore your programs in a deterministic machine for free. Get started in 5 minutes.

Simulate, fuzz and explore your software yourself or with AI coding agents.
















Stop hoping the bug happens again.


Race conditions, timing issues, and network failures show up once in a while, and almost never when you are looking for them. Machine runs your real, unmodified Linux x86_64 software, from a single binary to a Docker Compose project, in a machine that controls time, interrupts, random numbers and the thread schedule. Every run can be replayed exactly and branched from any point.


So instead of running a test thousands of times, you name the race and make it happen.

See a missed wakeup forced and fixed →










    

        
Fine-grained control over execution

        
Let your AI coding agent test your code and its bug fixes, or do it yourself. Every run is deterministic, so every failure you find replays exactly.

        

            

                

                
                
AI agents test your code

                
Your AI coding agent runs your code and its fixes in the machine. Every failure it finds replays exactly, for it and for you.

                

                The skill for coding agents
            

            

                

                
                
Precise fault injection

                
Fail a system call, a disk request, a packet or a container at the exact call you choose, or at random from a seed.

                

                Fault injection
            

            

                

                
                
Forced data races

                
Hold, yield and pin threads to force the interleaving that triggers a race. Then watch the same race on every replay.

                

                Holding threads
            

            

                

                
                
Custom fuzzers

                
Draw schedules, faults and timing from a seed in Python, or schedules from a plan file with no code, and stress the code paths you choose.

                

                Plans
            

            

                

                
                
Retroactive logging

                
Log everything, store nothing. Replay the stretch you care about and get its logs after the fact.

                

                Dropped output
            

            

                

                
                
Time travel

                
Rewind to any checkpoint, step back to the instruction before a bug, or branch from any point. The original run stays as it was.

                

                Going back
            

            

                

                
                
Time compression

                
Idle time is skipped. Ten minutes of sleep in the machine pass in about three seconds, so timeouts and retries cost seconds.

                

                Time compression
            

            

                

                
                
Debugging at any point

                
Inspect registers, memory and the stack, set breakpoints and watchpoints, or run GDB inside the machine, at any point of any run.

                

                Debugging
            

        

    












Built for AI agents. Controlled by you.


Agents do the heavy lifting, while you stay in the loop and can see every step they take, repeat it, and take over at any point. Your agent drives Machine through the same machine client that you use, and the Python SDK gives both of you full programmatic control.


Install the Machine skill, ask your agent what Machine can do for your project, and it sets things up with you.
