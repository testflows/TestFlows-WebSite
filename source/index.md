<h2 class="home-section-title home-section-title-left">Stop hoping the bug happens again.</h2>
<p class="home-section-lead home-section-lead-left">Race conditions, timing issues, and network failures show up once in a while, and almost never when you are looking for them. Machine runs your real, unmodified Linux x86_64 software, from a single binary to a Docker Compose project, in a machine that controls time, interrupts, random numbers and the thread schedule. Every run can be replayed exactly and branched from any point.</p>
<p class="home-section-lead home-section-lead-left">So instead of running a test thousands of times, you name the race and make it happen.</p>
<a class="home-step-more" href="/blog/introducing-testflows-machine-self-service-deterministic-simulation-testing-environment/#what-this-looks-like">See a missed wakeup forced and fixed <span aria-hidden="true">&rarr;</span></a>
</div>

<title id="mw-title">The missed wakeup in missed-wakeup.c</title>

<h2 class="home-section-title home-section-title-left">From a failure to a verified fix.</h2>
<div class="home-step-grid">
<article class="home-step">
<div class="home-step-head"><p class="home-step-num">01</p><span class="home-step-icon"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.1" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><circle cx="12" cy="12" r="8.5"/><circle cx="12" cy="12" r="3.2"/></svg></span></div>
<h3>Record every run</h3>
<p>Every run is recorded as it executes. A replay repeats it exactly, to the instruction, as often as you like.</p>
<a class="home-step-more" href="/docs/machine/#replay">Replay <span aria-hidden="true">&rarr;</span></a>
</article>
<article class="home-step">
<div class="home-step-head"><p class="home-step-num">02</p><span class="home-step-icon"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.1" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><circle cx="6" cy="5" r="2"/><circle cx="6" cy="19" r="2"/><circle cx="18" cy="7" r="2"/><path d="M6 7v10"/><path d="M18 9c0 4.5-6 3.5-11.2 8.6"/></svg></span></div>
<h3>Branch from any point</h3>
<p>Checkpoint the whole machine and fork a branch from any point. Each branch goes its own way while the original stays as it was.</p>
<a class="home-step-more" href="/docs/machine/#checkpoints-and-branches">Checkpoints and branches <span aria-hidden="true">&rarr;</span></a>
</article>
<article class="home-step">
<div class="home-step-head"><p class="home-step-num">03</p><span class="home-step-icon"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.1" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><circle cx="12" cy="12" r="7"/><circle cx="12" cy="12" r="1.6"/><path d="M12 2.5v4M12 17.5v4M2.5 12h4M17.5 12h4"/></svg></span></div>
<h3>Force the bug</h3>
<p>Hold a thread in a race window, fail the exact system call, or delay a packet, and make the machine produce the failure the code points at.</p>
<a class="home-step-more" href="/docs/machine/#steering-programs">Steering programs <span aria-hidden="true">&rarr;</span></a>
</article>
<article class="home-step">
<div class="home-step-head"><p class="home-step-num">04</p><span class="home-step-icon"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.1" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><rect x="7.5" y="8" width="9" height="12" rx="4.5"/><path d="M9.5 8a2.5 2.5 0 0 1 5 0"/><path d="M12 12v8"/><path d="M7.5 12H4M16.5 12H20M7.5 16.5l-3 1.5M16.5 16.5l3 1.5M8 9.5 5.5 7.5M16 9.5l2.5-2"/></svg></span></div>
<h3>Debug at any point</h3>
<p>Read registers, memory and the stack, set breakpoints and watchpoints, or run GDB inside the machine, at any point of any run.</p>
<a class="home-step-more" href="/docs/machine/#debugging">Debugging <span aria-hidden="true">&rarr;</span></a>
</article>
<article class="home-step">
<div class="home-step-head"><p class="home-step-num">05</p><span class="home-step-icon"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.1" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><circle cx="12" cy="12" r="8.5"/><path d="m8.2 12.3 2.6 2.6 5-5.4"/></svg></span></div>
<h3>Verify the fix</h3>
<p>Run the same interleaving against your fix. When it passes, you know the fix holds, not just that the failure has not shown up yet.</p>

import testflows.machine.v1 as machine

client = machine.Client()
with client.sessions.create(cpus=2) as session:
    client.sessions.use(session)
    run = client.create("app", disk="app", cpus=2)
    run.run(until="console~ready", within="30s")

    branch = run.fork(at="^ready", name="try-1")

(function () {
    document.querySelectorAll("[data-home-tabs]").forEach(function (root) {
        var tabs = Array.prototype.slice.call(root.querySelectorAll('[role="tab"]'));
        function select(tab) {
            tabs.forEach(function (t) {
                var on = t === tab;
                t.setAttribute("aria-selected", on ? "true" : "false");
                t.tabIndex = on ? 0 : -1;
                document.getElementById(t.getAttribute("aria-controls")).hidden = !on;
            });
        }
        tabs.forEach(function (tab, i) {
            tab.addEventListener("click", function () { select(tab); });
            tab.addEventListener("keydown", function (e) {
                var d = e.key === "ArrowRight" ? 1 : e.key === "ArrowLeft" ? -1 : 0;
                if (!d) { return; }
                var next = tabs[(i + d + tabs.length) % tabs.length];
                select(next); next.focus(); e.preventDefault();
            });
        });
    });
})();
